# Exercism solutions (sync)

This repository is a synchronized mirror of my Exercism solutions organized under the "solutions" workspace/tracks. It primarily contains my Go track solutions (majority Go, some Rust).

Purpose
- This repo is a sync copy of Exercism tracks under the `solutions` workspace and is maintained to keep a single, searchable archive of completed exercises.

Structure
- Each track (for example `go/` or `rust/`) contains exercises and their solutions organized by exercise name.

Notes for contributors
- This repository is intended as a sync/mirror, not the canonical submission source for Exercism exercises. If you want to propose changes to solutions themselves, please edit the source in the original `solutions` workspace/repository.
- Small fixes to README or metadata are welcome via pull requests.
